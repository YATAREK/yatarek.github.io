Tool 01 · Forward Design

High-Entropy Superconductor
Tc Prediction

A two-stage pipeline that first classifies phase stability, then predicts the superconducting critical temperature across six regression models. Covers BCC, FCC, intermetallic, and amorphous phase categories. Literature nearest-neighbours and Materials Project binary data provide physical context alongside the ML estimate.

Tool 02 · Inverse Design

HES Compositions
for a Target Tc

Given a target critical temperature, this tool screens all equimolar 4, 5, and 6 element combinations from a chosen pool of refractory metals. Each candidate must pass a five-check verification gate covering phase stability, cross-model agreement, valence electron count, physical Tc bounds, and novelty. Survivors are ranked by a composite objective function.

Tool 03 · Electrode Design

Carbon Supercapacitor
Inverse Design

A physics-informed Gaussian process regressor predicts specific capacitance from electrode descriptors including specific surface area, pore size, nitrogen content, and current density. Seven physics-derived features encode the Gouy-Chapman-Stern double-layer model. Bayesian optimisation with Expected Improvement then solves the inverse problem: identifying synthesis targets for a desired capacitance.

Known Limitations
Sparse HEA training data
Only 66 of 3,319 Tc training samples are high-entropy alloys. Cross-validation metrics reflect the full dataset, not HEA-specific accuracy, which is likely 2 to 3 times worse.
No negative superconductivity labels
The regression models always return a positive Tc. They cannot recognise when an alloy fails to superconduct. Non-superconducting alloys produce false predictions.
Magnetic element suppression
Fe, Co, Ni, and Mn break Cooper pairs and suppress superconductivity. Compositions rich in these elements should be treated with caution regardless of the predicted Tc.
Supercapacitor model responds only to SSA
In the currently deployed version, only total specific surface area changes the predicted capacitance. The remaining descriptors do not yet affect the output. Retraining is needed.
Extrapolation overestimates performance
Random cross-validation on a single database overestimates generalisation to new chemical families. Results on novel HEA classes should be treated as hypotheses, not predictions.
Phase gate domain restriction
The Stage 1 phase classifier applies only to alloys with 4 to 6 elements, each present at 5 to 35 atomic percent. Inputs outside this domain are flagged but not blocked.
Ongoing development

A physics-informed HEA-specific model is in development, combining DFT electronic structure data from LeMaterial with the 46-entry experimental dataset to produce a model grounded in BCS theory. An active learning loop and a retrained supercapacitor surrogate are planned next.
